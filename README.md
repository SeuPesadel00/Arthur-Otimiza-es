# Capital Daark - Game Booster & PC Optimization Suite

Suíte de otimização automatizada para Windows (10 e 11) focada em alta performance gamer, redução de latência/input lag e estabilidade de sistema.

## Ferramentas Inclusas:
- **Capital Daark Booster (.bat)**: Script automatizado com tweaks de sistema, debloater, rede e prioridade para mais de 40 jogos.
- **DNS Jumper v2.3**: Troca rápida e teste dos servidores DNS mais velozes.
- **EmptyStandbyList**: Limpeza de cache de memória RAM standby em tempo real.
- **Autoruns (Microsoft Sysinternals)**: Diagnóstico e controle avançado de inicialização do Windows.
- **Open Hardware Monitor**: Monitoramento em tempo real de temperaturas e frequências de CPU e GPU.
