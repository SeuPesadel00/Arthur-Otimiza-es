Perguntas Frequentes

O script pode danificar meu computador? +
Não. O script realiza ajustes em parâmetros normais do Windows e políticas de desempenho. Além disso, disponibilizamos a Opção 1 (Ponto de Restauração) e o menu de reversão para que você possa voltar ao estado anterior com facilidade a qualquer instante.
Qual a diferença entre baixar em .ZIP ou .RAR? +
O conteúdo dentro de ambos é exatamente idêntico. O formato .ZIP é recomendado porque pode ser aberto nativamente em qualquer Windows sem precisar de nenhum programa extra. O formato .RAR é para quem já possui WinRAR instalado.
Preciso manter o script aberto enquanto jogo? +
Não! Uma vez aplicadas as otimizações e tweaks de registro, elas ficam salvas no sistema operacional. Você pode fechar o script e abrir seu jogo normalmente. A única exceção é a limpeza de RAM, que você pode executar sempre que sentir a memória pesada.
Funciona tanto no Windows 10 quanto no Windows 11? +
Sim! O script foi compatibilizado e testado para as versões modernas de 64-bit do Windows 10 e Windows 11.
